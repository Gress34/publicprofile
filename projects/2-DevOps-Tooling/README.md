# DevOps Tooling

This project showcases a collection of DevOps tools and scripts for CI/CD, infrastructure automation, and cloud operations. It includes tools for testing, deployment, and monitoring.

## Features
- CI/CD pipelines using GitHub Actions.
- Infrastructure testing with Docker and Kubernetes.
- Monitoring and observability using Prometheus and Grafana.
- Security testing with tools like OWASP ZAP and SonarQube.
- Deployment strategies, including blue-green and canary deployments.

## How to Use
1. Clone the repository.
2. Install Docker and Kubernetes.
3. Run `docker build -t devops-tooling .` to build the container.
4. Deploy using Kubernetes with `kubectl apply -f deployment.yaml`.
5. Use GitHub Actions for CI/CD.
