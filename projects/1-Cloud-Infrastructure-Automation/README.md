# 1-Cloud-Infrastructure-Automation

This project demonstrates how to automate cloud infrastructure using Terraform and Ansible. It includes scripts and configurations for creating scalable, secure, and reliable cloud environments.

## Features
- Terraform scripts for provisioning AWS resources.
- Ansible playbooks for configuring servers and services.
- Security best practices, including IAM roles and least-privilege access.
- Scalable API and durable storage configurations.

## How to Use
1. Clone the repository.
2. Install Terraform and Ansible.
3. Run `terraform apply` to provision the infrastructure.
4. Run `ansible-playbook configure_servers.yml` to configure the servers.
